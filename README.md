# NLP Learning Journey

An undergraduate learning portfolio documenting a gradual path through natural language processing, from recurrent networks to modern language models.

## Learning progress

- **Completed — theory:** RNN, LSTM, GRU, and the basic encoder–decoder approach to sequence-to-sequence learning.
- **In progress:** PyTorch fundamentals and translating theoretical understanding into practical implementations.
- **Planned:** Attention, Transformer, BERT, large language models, and reproducible NLP training projects.

The completed items refer to theoretical study. No complete model-training experiment or performance result is claimed here.

## Learning source

The notes are newly generated summaries based on the learner's stated course topics and general NLP concepts. Selected diagrams are reproduced from a course handout; the complete handout is not redistributed here. Consult the original course for the full instructional material.

## Updating this portfolio

For each new topic, add a note in `notes/`, update the progress list, and record any code or experiment only when it actually exists. For experiments, document the data source, environment, method, results, and limitations. Review changes and sensitive information before committing and pushing.
